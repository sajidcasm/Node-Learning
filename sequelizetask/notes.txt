ORM kya hai?

ORM = Object Relational Mapping

Ye ek library/technology hai jo tumhare JavaScript objects ko SQL database se connect karti hai.

ORM tumhare JavaScript code ko SQL queries me convert karta hai.

Tum likhte ho:
await User.findAll();

ORM isko andar hi andar convert karta hai:
SELECT * FROM users;

Aur tum likhte ho:
await User.create({
  name: "Sajid",
  age: 23,
});

cnvert krta hai : 
INSERT INTO users(name, age)
VALUES ('Sajid', 23);


2. Model kya hai?

Backend: ORM 
const User = sequelize.define("User", {

Ye User hi Model hai.

Sequelize ek ORM (Object Relational Mapping) library hai jo Node.js me SQL databases ke saath kaam karne ke liye use hoti hai.

Iska kaam hai JavaScript aur SQL ke beech bridge banna.

Without Sequelize (Raw SQL)
const query = `
  SELECT * FROM users WHERE id = 1
`;

await client.query(query);
